# Aplicación web Alon

Interfaz de gestión adaptable construida con React, TypeScript y Vite. Incluye una maqueta de navegación y datos ficticios locales para explorar los listados de 100 artículos, 20 clientes y 20 proveedores. Los datos se generan en el frontend y todavía no se guardan en MySQL ni son datos de comercios reales.

## Desarrollo

```bash
npm install
npm run dev
```

La versión de Node.js debe cumplir los requisitos de Vite.
